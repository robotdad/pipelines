# ledgerfmt

Reference implementation and normative specification of the **LedgerLine v1**
plain-text ledger format.

- [`SPEC.md`](./SPEC.md) is the authoritative format specification.
- [`ledgerfmt/parser.py`](./ledgerfmt/parser.py) is a reference parser.
- [`examples/`](./examples/) holds small valid and invalid samples.

This repository is read-only reference material.
